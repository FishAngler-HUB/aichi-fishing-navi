# 毎朝の自動更新（Windows タスク スケジューラ）設定手順

毎朝6:00に「天気・海況データの取得 → forecast.json 更新 → GitHub へ反映」を自動で行う設定です。
Windows 初心者でも設定できるように順番どおりに進めてください。

---

## 事前準備（1回だけ）

1. **Node.js** がインストールされていること

   - コマンドプロンプトで `node -v` と入力してバージョンが表示されればOK
   - 入っていなければ https://nodejs.org/ja から「LTS」版をインストール
2. **手動で一度動かして確認**

   - エクスプローラーで
     `釣り場おすすめ情報ツール\tools\run-update.bat`
     をダブルクリック
   - 黒い画面が開き、処理が終わると閉じます
   - `tools\fetch.log` に実行結果が追記されていればOK

> この時点では「git リポジトリではないため push はスキップ」と記録されます。
> GitHub 公開（ステップ6）が終わると、自動で commit / push まで行われるようになります。

---

## タスク スケジューラに登録する

### 1. タスク スケジューラを開く

- キーボードの **Windows キー** を押して `タスク スケジューラ` と入力し、開く

### 2. 新しいタスクを作る

- 右側の **「基本タスクの作成」** をクリック

### 3. 名前

- 名前：`釣り情報ツール 天気更新`
- 「次へ」

### 4. いつ実行するか

- **「毎日」** を選んで「次へ」
- 開始時刻：`6:00:00`
- 「次へ」

### 5. 何を実行するか

- **「プログラムの開始」** を選んで「次へ」
- **「プログラム/スクリプト」** の欄の右の「参照」を押し、次のファイルを選ぶ：
  ```
  釣り場おすすめ情報ツール\tools\run-update.bat
  ```
- 「引数の追加」「開始（オプション）」は **空のままでOK**
  （run-update.bat が自分でフォルダを移動します）
- 「次へ」→「完了」

### 6. 追加の設定（推奨）

- 作成したタスクを一覧で右クリック →「プロパティ」
- **「全般」タブ**
  - **「ユーザーがログオンしているときのみ実行する」を選ぶ**
    （＝上のラジオボタン。**パスワードは聞かれません**）
  - 「最上位の特権で実行する」は **チェックなしでOK**

  > ⚠️ もう一方の「ユーザーがログオンしているかどうかにかかわらず実行する」を選ぶと
  > Windowsのアカウントパスワードを求められます。今回は不要なので選ばないでください。
  > （Microsoftアカウントでサインインしていて普段はPIN／顔認証だけ、という場合は
  > 　そもそもパスワードが分からないことが多いです）

- **「条件」タブ**
  - 「コンピューターをAC電源で使用している場合のみタスクを開始する」の
    チェックを外す（ノートPCでバッテリー時も動かしたい場合）
  - 6:00にPCがスリープ中でも動かしたいなら
    「タスクの実行時にスリープを解除する」にチェック（パスワード不要）
- **「設定」タブ**
  - 「スケジュールされた時刻にタスクを開始できなかった場合、すぐにタスクを開始する」に
    チェック（6:00にPCが起動していなくても、サインイン後に実行される）
- 「OK」

> 「ログオンしているときのみ実行」でも、毎朝PCを使うなら実用上は問題ありません。
> サインインしていない時間帯は動きませんが、次にサインインしたときに自動で実行されます。

### 7. 動作テスト

- 一覧で作成したタスクを右クリック →「実行する」
- 数十秒後、`tools\fetch.log` に新しい実行結果が追記されていれば成功

## うまくいかないときの確認場所

| 症状                             | 確認すること                                                                  |
| -------------------------------- | ----------------------------------------------------------------------------- |
| パスワードを求められる           | 「全般」タブで「ユーザーがログオンしているときのみ実行する」を選ぶ（手順6）  |
| タスクは動くがログが増えない     | タスクの「操作」で選んだファイルが `run-update.bat` になっているか           |
| `node` が見つからない            | Node.js がインストールされているか（`node -v`）。再インストール後はPC再起動  |
| 取得は成功するが push されない    | GitHub のリポジトリと origin が設定されているか（公開済みなら設定済み）      |
| 前回の結果を見たい               | `tools\fetch.log` を開く（毎回下に追記されます）                             |

## 手動で実行したいとき

次のどちらでも、タスク スケジューラと同じ処理が動きます。

- `tools\run-update.bat` をダブルクリック
- または、プロジェクトフォルダで `npm run update:forecast`

天気だけ取り直したいとき（git 操作なし）：`npm run fetch:forecast`

表示を確認したいとき：`npm run dev` → ブラウザで http://localhost:5500
