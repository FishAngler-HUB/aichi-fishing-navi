# data フォルダについて

「今日のおすすめ釣り場」機能で使うデータファイルです。
**すべて手で編集できる JSON**です。内容を直すとおすすめの判定結果が変わります。

| ファイル | 中身 | 誰が更新するか |
|---|---|---|
| `spots.json` | 釣り場の一覧と特徴（対象魚・風をかわせる向き・足場など） | あなた（気づいたときに修正） |
| `fish.json` | 魚種ごとの生態（旬の月・ベイト・適水温・風波の許容など） | あなた（気づいたときに修正） |
| `forecast.json` | 全釣り場×3日分の天気・海況 | **スクリプトが毎朝自動生成**（手で触らない） |
| `now_biting.json` | 「今の狙い目」表示の手動上書き（任意） | あなた（任意。無ければ `fish.json` の旬から自動表示） |

## 注意

- `spots.json` / `fish.json` の特徴値は、愛知県の一般的な釣り場情報をもとにした**下書き**です。
  実際に通っている場所の感覚に合わせて自由に直してください。
- 方角の表記は `北 / 北東 / 東 / 南東 / 南 / 南西 / 西 / 北西` の8方位で統一しています。
- `spots.json` はこのおすすめ機能専用です。既存の「地域を選択→釣り場を選択」機能は
  これまで通り `script.js` 内のデータで動いており、影響はありません。

## spots.json の各項目

| 項目 | 意味 |
|---|---|
| `type` | 釣り場のタイプ（漁港 / 堤防 / 海釣り公園 / サーフ / 磯 / 島 など） |
| `targetFish` | その釣り場で狙える主な魚（`fish.json` の魚種名と合わせる） |
| `shelterWind` | この向きの風なら比較的かわしやすい（加点対象） |
| `exposedWind` | この向きの風に弱い・釣りづらい（減点対象） |
| `maxWaveComfort` | 快適に釣りできる波高の目安（m）。これを超えると減点 |
| `footing` | 足場。`good`（整備・安全） / `normal`（普通） / `caution`（テトラ・サーフ等で注意） |
| `nightLight` | 常夜灯があるか（夜行性の魚で加点） |
| `familyFriendly` | 家族連れでも行きやすいか |

## fish.json の各項目

| 項目 | 意味 |
|---|---|
| `seasonMonths.best` | 最盛期の月（1〜12） |
| `seasonMonths.ok` | そこそこ釣れる月 |
| `bait` | 季節ごとのベイト（春=3〜5 / 夏=6〜8 / 秋=9〜11 / 冬=12〜2） |
| `water.tempMin` / `water.tempMax` | 釣りやすい海水温の目安（℃） |
| `windMaxComfort` | 快適に釣りできる風速の目安（m/s）。超えると減点 |
| `waveMaxComfort` | 快適に釣りできる波高の目安（m）。超えると減点 |
| `prefersMazume` | 朝夕まづめ狙いが特に有利か（理由文に表示） |
| `prefersNightLight` | 夜の常夜灯まわりが有効か（常夜灯ありの釣り場で加点） |
| `spotTypes` | 相性の良い釣り場タイプ |
